# Axiom Orbit UI Reference Pack

This package contains the approved visual direction for the Client Growth / Axiom Orbit frontend redesign.

## Files

- `MASTER_PROMPT.md` — paste this into the coding agent as the primary redesign instruction.
- `AGENT_WORKFLOW.md` — recommended skills and execution order.
- `images/00_overview_approved_direction.png` — approved overall visual language.
- `images/01_home.png` — Home reference.
- `images/02_clients.png` — Clients reference.
- `images/03_opportunities.png` — Opportunities reference.
- `images/04_opportunity_detail.png` — Opportunity detail reference.
- `images/05_settings_services.png` — Settings / Services reference.

## Best way to use it

Attach or place the entire pack inside the agent's accessible workspace, then tell the agent:

> Read `MASTER_PROMPT.md` and `AGENT_WORKFLOW.md`, inspect every image in `images/`, then inspect the existing repository. Treat the images as the approved visual source of truth and preserve the application's real functionality/data. Follow the implementation and screenshot-comparison loop exactly. Do not redesign the concept again.

The sample data visible in the images is illustrative. The implementation should use the real application's data and behavior.
